# Stakeholder Bedrijfsprofielen

> Deze map bevat profielbestanden voor alle stakeholderbedrijven.
> Maak per bedrijf één bestand aan via het `/add-stakeholder` commando of gebruik het sjabloon hieronder.

## Aanmaken

```
/add-stakeholder
```

Of kopieer het sjabloon `_template.md` naar `<bedrijfsnaam>.md` en vul het in.

## Gebruik

Geef de Business Analyst opdracht een gesprek te voeren:

```
@Business Analyst Ga naar [BedrijfsNaam] met als doel: [doel].
Lees agents/stakeholders/[bedrijfsnaam].md voor het bedrijfsprofiel.
```

Of gebruik het prompt:
```
/interview-stakeholder
```
